# MEMBRA Protocol

Membra_api is the system of record.

This repo follows the shared Membra protocol for owners, advertisers, assets, campaigns, placements, media kits, QR/NFC identities, proof events, audit events, and payout eligibility.

Master invariant: no verified owner, no asset; no verified asset, no campaign match; no approved creative, no media kit; no proof, no payout eligibility.
